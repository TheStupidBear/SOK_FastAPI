Вэб-приложение для 3d печати с примерами работ и характеристик печати.

[Автор](https://www.linkedin.com/in/dmitri-stepanov-aa5904399/)
Выбираете определенного производителя филамента, его тип, цвет, и вам откроется примеры работ других пользователей с характеристиками печати. 
Можно добавить цвет по hex коду и самому добавить пример работы (только для авторизованных пользователей).
Есть поиск по hex коду.

Все данные хранятся в БД (Sqlite3).

Проект запускается с main.py (до запуска установите небходимые библиотеки - requirements.txt)
